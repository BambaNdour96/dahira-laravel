# Corriger un paiement validé

Avant sa validation, une déclaration se **refuse** (avec un motif). Une fois validée, elle ne se supprime jamais : elle
se **corrige**, par le **Jewrine finance national** seul (le super administrateur en secours), avec un **motif
obligatoire**. Le membre est prévenu, et tout est journalisé.

Trésorerie → **Paiements** → onglet « Confirmés » → le paiement → **Corriger**. Les corrections portent sur les
**cotisations** et les **versements des programmes** (pas sur les frais de carte ni le renouvellement).

| Correction | Ce qui se passe |
| --- | --- |
| **Annuler (contre-passer)** | Une écriture inverse : l'argent sort de la caisse où il était entré (de la **caisse générale** si le représentant l'a déjà remis) ; refusée si le solde de cette caisse ne suffit pas. Les mois de cotisation redeviennent dus. Le reçu reste, avec la mention **« ANNULÉ »** ; le paiement passe dans l'onglet « Annulés » |
| **Réaffecter** | Le paiement compte pour autre chose (une cotisation devient un Jàyante, un versement passe à un autre programme) : il est remplacé par un **paiement nouveau, avec son reçu** ; l'argent reste dans sa caisse (le journal de la caisse montre le passage d'une affectation à l'autre, sans changer le solde). Vers une cotisation, le montant doit couvrir des mois entiers |
| **Transformer en avoir** | Le paiement devient un **crédit** sur le compte du membre ; l'argent reste dans sa caisse. Trésorerie → **Avoirs** → « Imputer » : la Finance l'utilise à la main, en tout ou en partie, pour une cotisation ou un Jàyante (« payé par avoir » : le solde de la caisse ne change pas, le journal montre l'argent passer de l'avoir au paiement). Le membre voit son avoir sur « Mes cotisations » |
| **Rembourser** | Un **ordre de dépense** de remboursement est demandé (bénéficiaire : le membre). Le Jewrine national le signe, la Finance le paie ; le paiement n'est annulé qu'à ce moment. Si l'ordre est refusé, le paiement reste valide |

Les mois de cotisation d'un paiement corrigé restent dans l'historique, marqués annulés : ils ne s'effacent jamais.
